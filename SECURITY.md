# Security policy

## Supported versions

Security fixes are applied to the latest code on the default branch. The project
does not currently maintain separate long-term-support branches.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users or
their captured data at risk. Use GitHub's **Security → Report a vulnerability**
flow for this repository. Include the affected version or commit, reproduction
steps, impact, and any suggested mitigation.

If private vulnerability reporting has not yet been enabled for the repository,
open a public issue containing no exploit details and ask the maintainer for a
private contact channel.

Good-faith reports will be acknowledged as soon as practical. Please allow time
for investigation and a coordinated fix before public disclosure.
