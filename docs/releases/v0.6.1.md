# Better SS 0.6.1

The core Windows download is now about 17 MB. Screenshot capture, image editing and export, Live OCR, and the color picker remain included.

Screen recording and video editing are optional. Choose them in **Preferences → Optional features** or accept the download prompt when you first use either one. They share one download and work offline after installation.

Setup installs the .NET 8 x64 Desktop Runtime if it is not already present. Video tools are downloaded only after the user chooses to install them.
